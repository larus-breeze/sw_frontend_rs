\section{\hr{Operation}}

\tr{The following sections describe the various display modes. The device provides
three basic displays: Vario, Horizon and Device Information. You can switch between the displays
by briefly pressing the button and selecting the Display item in the menu.
The selected display remains permanently (even after restarting).}

\subsection{Vario Display}

\tr{The central display distinguishes between the circling mode and the straight flight mode. If a
rotational speed of at least 1°/sec is measured for more than 10 seconds, thecircling mode is activated. If the rotational speed falls below this value for more than 10 seconds,
the display switches back to the straight flight mode.}


\picnote
	{pictograph-blue-cloud.pdf}
	{\tr{The change from variometer mode to speed to fly mode is independent of the change in the central display information.}}

\tr{For further information, please refer to the chapter "Switching from circuits (Vario) to speed to fly".}

\subsubsection{\hr{Circling Mode}}

\begin{figure}[H]
    \centering
    \includegraphics[width=15cm]{circling-explained.pdf}
    \caption{\tr{Advertisement in circling mode}}
    \label{fig:circling-explained}
\end{figure}

\tr{The displays Info 1, Info 2, Info 3 and the central display depend on whether you are flying straight ahead
or in a circle. The content of these displays can be set for both modes.}

\tr{Contents of the circling mode:}
\begin{itemize}
	\item 	\tr{News climb rate}
	\item 	\tr{Average climb rate}
	\item 	\tr{MacCready value}
	\item 	\tr{Central display, here thermal assistant}
	\item 	\tr{Info 1 display, here time}
	\item 	\tr{Info 2 display, here wind direction and wind strength}
	\item 	\tr{Info 3 Display, here average climb rate since the start of circling}
	\item 	\tr{The colour of the Sat symbol indicates the data quality:}
	\begin{itemize}
		\item 	\tr{Green: Connection to LARUS sensor unit established. Device has GPS fix.}
		\item	\tr{Yellow: Connection to LARUS sensor unit established, unit has no GPS fix}
		\item 	\tr{Red: No connection to the LARUS sensor unit}
	\end{itemize}
	\item 	\tr{The colour of the battery symbol corresponds to the operating voltage:}
	\begin{itemize}
		\item 	\tr{Green: The battery voltage is sufficient.}
		\item	\tr{Yellow: The battery voltage is in the critical range.}
		\item 	\tr{Red: The battery voltage is below the minimum value.}
	\end{itemize}
\end{itemize}

    conditions.}}

\begin{figure}[H]
    \centering
    \includegraphics[width=5cm]{horizon.png}
    \caption{\tr{Artificial horizon}}
    \label{fig:horizont}
\end{figure}

\tr{The artificial horizon display contains the following information:}
\begin{itemize}
	\item \tr{The blue area represents the sky.}
	\item \tr{The border of the brown area corresponds to the horizon.}
	\item \tr{The circular scale at the top shows the current bank angle of the aircraft in 15° increments (here approximately 30°, red arrowhead).
The horizontal axis shows the current pitch angle of the aircraft in 15° increments (here approximately 10°, red arrowhead).}
	\item \tr{The scale parallel to the horizon represents the angle of ascent/descent in 10° increments
(here 0°).}
	\item \tr{inclinometer s can be seen in the lower section, which reveal any shifting.
            .}
\end{itemize}

\tr{The aeroplane is currently in a clean right turn with a bank angle of 30°.}

\subsubsection{\hr{Switching from Vario to Speed to Fly}}

\tr{Switching the sound information from Vario speed to fly depends on your
Vario Control configuration:}
\begin{itemize}
	\item	\tr{Car: below 1.1 times the speed for best gliding:
Vario mode, above: speed to fly mode. If you are in Vario mode and
continue to circle, Vario mode remains active even if you exceed this
speed limit.}
	\item	\tr{Button or switch: For using an external switch, e.g. on the control stick or flap lever.
            or flap lever.}
	\item	\tr{Remote control joystick.}
\end{itemize}


\subsubsection{\hr{Acoustic Quiet Zone in Speed to Fly E Mode}}

\tr{You can set a speed range in which the acoustic speed to fly signal
is muted. In the factory setting, the audio signal is deactivated in a range of +/- 10 km/h
.}


\subsection{\hr{Controls}}

\tr{The device has a rotary knob with two levels and a push button. The following functions are assigned to the button and the
two rotary knobs:}
\begin{itemize}
	\item	\tr{Turn the small/upper knob: Volume control}
	\item	\tr{Turn the large/lower knob: MacCready value}
	\item	\tr{Briefly press the rotary knob:  } Flight Menu
	\item	\tr{Press and hold the rotary knob: } Settings Menu
\end{itemize}
