\subsection{\hr{Quick Start Guide}}

\tr{In some cases, the default settings can be used and the device can be put into operation in a
    simplified manner. In this case, it is sufficient to observe the following
    points:}
\begin{enumerate}
	\item 	\tr{Please remove both rotary knobs using a 1.5 mm hex key (included in the
scope of delivery).}
	\item 	\tr{Secure the LARUS Vario display with three screws in a 57 mm recess in the instrument panel.
It can also be mounted at angles of 90°, 180° and 270°.}
	\item 	\tr{Fit both rotary knobs}
	\item 	\tr{Connect the CAN port of the LARUS Vario display and the LARUS sensor unit using
the 1:1 patch cable included in the scope of delivery.}
	\item 	\tr{Switch on LARUS.}
	\item 	\tr{Check whether the satellite icon on the screen is yellow or green and
            the current course direction is displayed.}
	\item 	\tr{Select a suitable polar for your glider or create one.}
	\item 	\tr{Your LARUS Vario display is now ready for flight.}	
\end{enumerate}

\subsection{\hr{Design and Function}}

\tr{The LARUS Vario Display shows the data measured and calculated by LARUS. LARUS is an
advanced variometer with real-time wind measurement capability. It features state-of-the-art pressure sensors,
an advanced IMU and GNSS receivers to capture accurate flight data. The key
features of the display are:}
\begin{itemize}
	\item 	\tr{Round display for 57 mm standard instrument panel cut-outs}
	\item 	\tr{Brighter and more colourful screen}
	\item 	\tr{Lightweight, compact design with black anodised aluminium housing}
	\item 	\tr{Rotary knob with two levels and push-button function for changing settings and
accessing menus 1.5 mm hex key.}
\end{itemize}

\tr{The LARUS Vario Display is developed and continuously improved by Prof. Dr. Klaus Schaefer, Maximilian Betz, Winfried Simon,
Peter Simon and the SteFly team. You are welcome to 
participate in the development and contribute suggestions for improvement or problems.}

\subsection{\hr{Firmware Update}}

\tr{The LARUS team continuously improves the software and publishes updates, for example
on the LARUS Vario Display website. To update the firmware, please save the new
.bin file to the SD card included in the scope of delivery and insert it into the
SD card slot of the LARUS Vario Display. The device only installs compatible
firmware versions that are higher than the installed version. After switching on, the
device starts up in less than a second. If compatible firmware is detected on the SD card,
the display remains black for about 3-5 seconds before the message "Firmware upgrade is
being performed" is displayed. The loaded firmware version is then displayed.

If the update does not start after switching on the device with an SD card inserted that contains a new
firmware version, please use another SD card.
SD card requirements: min. 4 GB SDHC, FAT32 format (not GPT).}
